## Bu Ne Ya?

Dünyanın en ciddi (olmayan) yazılım projesi. Sokakta bulduğun her kuruşun hayatını nasıl etkileyeceğini (etkilemeyeceğini) hesaplayan eşsiz bir algoritma.

**Özellikler:**
- Gerçekten çalışır
- Rastgele absürt senaryolar üretir
- Kaderini değiştirmez ama gününü kurtarır
- Hiçbir şeyi çözmez, sadece güldürür
- Türkçe, çünkü öyle istendi

## Nasıl Kullanılır?

```bash
python kader.py
```

Sonra sana kaç TL bulduğunu sorar. Sen sayı girersin. O da saçma sapan bir kader söyler. Hepsi bu.
